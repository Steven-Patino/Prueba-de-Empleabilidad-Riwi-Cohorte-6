# Power BI dashboard

This module is under development. Everything it needs is already produced by the other
modules; this file is the data contract the report is being built against. The `.pbix`
(or screenshots + the data file) will land in this folder.

## Data source

Use `data/reporte_pedidos.csv`, generated by the Airflow DAG `etl_pedidos_diario`
(module 3). If you did not run Airflow, you can use `dataset_pedidos_semilla.csv` at the
repo root instead.

### Columns of `reporte_pedidos.csv`

| column         | description                                                        |
|----------------|--------------------------------------------------------------------|
| `metrica`      | one of `tiempo_promedio_entrega_min`, `cantidad_pedidos`, `ingresos_totales` |
| `dimension`    | the zone (for time and revenue) or the status (for the count)     |
| `valor`        | the numeric value of the metric                                   |
| `fecha_reporte`| date the report was generated (UTC)                               |

The file is in long / tidy format, so in Power BI you can filter by `metrica` and build
each visual from the same table.

## Minimum requirements (from the assessment)

- At least 3 visuals: a bar chart (orders or revenue by zone), a line/area chart (orders
  per day), and a KPI card (total revenue or average ticket).
- At least 1 slicer (by status or by zone).
- At least 1 custom DAX measure.

For "orders per day" use the raw `dataset_pedidos_semilla.csv` (it has `fecha_creacion`
per order); the aggregated report does not carry a per-day breakdown.
